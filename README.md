## 8. How to Run

### Prerequisites

Install or configure the following tools:

- Python 3.x
- Jupyter Notebook
- Microsoft SQL Server and SQL Server Management Studio (SSMS)
- Microsoft Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone <your-repository-url>
cd data-analytics-project
```

### Step 2: Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Alternatively, if a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

### Step 3: Run the Python Analysis

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook in the `notebooks/` folder and run the cells sequentially.

### Step 4: Execute SQL Queries

1. Open SQL Server Management Studio.
2. Connect to your SQL Server instance.
3. Select or create the project database.
4. Run the SQL scripts available in the `sql/` folder.

Configure the database connection and import the required dataset before executing the queries.

### Step 5: Open the Power BI Dashboard

1. Open the `.pbix` file from the `dashboard/` folder in Power BI Desktop.
2. Update the data source paths or database connection if required.
3. Refresh the dataset to load the latest data.

### Step 6: Review the Report and Presentation

Open the files in the `reports/` and `presentation/` folders to review the final analysis and project findings.
